一、前端技术全景（从下往上递进）

基础
HTML（结构）+ CSS（样式）+ JavaScript（交互与逻辑）—— 所有框架最终都运行在这三者之上
框架
React / Vue / Angular / Svelte —— 解决如何高效组织 UI 与状态
工程化
Vite / Webpack / TypeScript / npm·pnpm —— 解决怎么开发、构建、提速
生态
路由 / 状态管理 / UI 组件库 / 请求库 —— 解决具体业务场景的复用

二、当前最常用框架对比

框架出品方核心特点优势适合
ReactMeta组件化 + 虚拟 DOM，JSX 写 UI生态最大、岗位最多中大型应用、团队
Vue尤雨溪/社区模板语法 + 响应式，渐进式上手快、中文文档好新手、快速开发
AngularGoogleTypeScript 原生、全家桶强约束架构规范、可维护大型企业系统
Svelte社区编译时框架、无虚拟 DOM包最小、运行最快轻量/高性能场景
怎么选：新手/快速出活 → Vue；冲就业/复杂应用 → React；大厂企业系统 → Angular；极致轻量 → Svelte。

三、工程化与生态（必须知道）

构建与开发服务器

  • Vite：现在默认的构建/开发服务器，启动和热更新秒级，比老牌 Webpack 快很多。
  • Webpack：老牌打包工具，配置灵活但偏重，存量项目常见。

语言与包管理

  • TypeScript：给 JavaScript 加类型，大项目几乎必备。
  • npm / pnpm：装第三方包的包管理器（React、Vue 本身也是「包」）。

常用生态零件

  • 路由：页面跳转（React Router / Vue Router）。
  • 状态管理：React 用 Redux/Zustand，Vue 用 Pinia。
  • UI 组件库：Ant Design、Element Plus 等。
  • 请求库：Axios，用于和后端通信。

四、快速上手：用 Vite 起一个 React 项目

1
安装 Node.js
到 nodejs.org 下载 LTS 版，一路下一步（自带 npm）。
2
创建项目npm create vite@latest my-app -- --template react
3
安装依赖并启动cd my-app && npm install && npm run dev浏览器打开提示的 http://localhost:5173 即可看到页面。
4
写代码 / 打包上线
改 src/App.jsx 就是改页面（热更新实时生效）。打包：npm run build生成的 dist/ 文件夹就是可部署的网站。
纯 HTML/CSS/JS（如桌面上的 login.html）也能做网站；框架解决的是「页面变复杂、状态变多时，还能高效写、改、维护」的问题。
